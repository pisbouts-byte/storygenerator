# Conversation starters

Paste these into the agent's "Conversation starters" / "Suggested prompts" configuration (usually
4 slots) when building it in Copilot Studio or Agent Builder.

1. **Build a backlog** — "Build an agile backlog from these requirements. Platform is Pega
   Constellation/Infinity, version 24.1, on-prem. This is a new build."
2. **Convert a transcript** — "Turn this meeting transcript into user stories grouped under epics
   and features."
3. **Split an oversized story** — "This story has 9 acceptance criteria — split it into smaller
   stories that satisfy INVEST."
4. **JIRA export** — "I've reviewed and approved this backlog draft — generate the JIRA CSV export
   using the standard field mapping."
